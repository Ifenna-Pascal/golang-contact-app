# Contact API

A CRUD REST API for managing contacts, built with [Gin](https://github.com/gin-gonic/gin), [sqlc](https://sqlc.dev) and PostgreSQL. Swagger docs are generated with [swag](https://github.com/swaggo/swag).

## Tech stack

| Concern | Tool |
| --- | --- |
| HTTP framework | Gin |
| Database | PostgreSQL (Docker) |
| Query layer | sqlc (type-safe Go generated from SQL) |
| Migrations | golang-migrate |
| Configuration | Viper (`app.env`) |
| API docs | swag + gin-swagger |

## Project structure

```
.
├── main.go                 # App entry point: config, DB connection, routes
├── app.env                 # Environment configuration
├── docker-compose.yaml     # PostgreSQL container
├── sqlc.yaml               # sqlc configuration
├── controllers/            # Request handlers
├── routes/                 # Route registration
├── schemas/                # Request payloads and response shapes
├── util/                   # Config loader
├── db/
│   ├── migration/          # SQL migrations (up/down)
│   ├── query/              # SQL queries sqlc reads
│   └── sqlc/               # Generated Go code (do not edit)
└── docs/                   # Generated Swagger docs (do not edit)
```

## Prerequisites

- [Go](https://go.dev/dl/) 1.26+
- [Docker](https://docs.docker.com/get-docker/) with Docker Compose
- [golang-migrate](https://github.com/golang-migrate/migrate) CLI
- [sqlc](https://docs.sqlc.dev/en/latest/overview/install.html) (only if you change the SQL)
- [swag](https://github.com/swaggo/swag) (only if you change the API annotations)
- [air](https://github.com/air-verse/air) (optional, for live reload)

## Getting started

### 1. Configure the environment

Create `app.env` in the project root:

```env
DB_DRIVER=postgres
DB_SOURCE=postgresql://<user>:<password>@localhost:5432/<database>?sslmode=disable
POSTGRES_USER=<user>
POSTGRES_PASSWORD=<password>
POSTGRES_DB=<database>
SERVER_ADDRESS=8000
```

| Variable | Description |
| --- | --- |
| `DB_DRIVER` | Database driver, `postgres` |
| `DB_SOURCE` | Connection string the API uses |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | Credentials the Postgres container is created with |
| `SERVER_ADDRESS` | Port the API listens on |

### 2. Start PostgreSQL

```bash
docker-compose up -d
```

### 3. Enable the UUID extension

The `contacts` table uses `uuid_generate_v4()`, which needs the `uuid-ossp` extension. Run this once per database:

```bash
docker exec -it postgres psql -U <user> -d <database> -c 'CREATE EXTENSION IF NOT EXISTS "uuid-ossp";'
```

### 4. Run the migrations

```bash
migrate -path db/migration -database "postgresql://<user>:<password>@localhost:5432/<database>?sslmode=disable" -verbose up
```

To roll back, replace `up` with `down`.

### 5. Run the API

```bash
go mod download
go run main.go
```

Or with live reload:

```bash
air
```

The API is served at `http://localhost:8000/api`.

## API

Base URL: `http://localhost:8000/api`

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/healthcheck` | Health check |
| `POST` | `/contacts/` | Create a contact |
| `GET` | `/contacts/` | List contacts (`page`, `limit` query params) |
| `GET` | `/contacts/:contactId` | Get a contact by ID |
| `PATCH` | `/contacts/:contactId` | Update a contact |
| `DELETE` | `/contacts/:contactId` | Delete a contact |

Interactive Swagger UI: <http://localhost:8000/swagger/index.html>

### Contact fields

| Field | Type | Notes |
| --- | --- | --- |
| `contact_id` | UUID | Generated by the database |
| `first_name` | string | Required on create |
| `last_name` | string | Required on create |
| `phone_number` | string | Required on create, must be unique |
| `street` | string | Required on create |
| `created_at` | timestamp | |
| `updated_at` | timestamp | |

### Examples

Create a contact:

```bash
curl -X POST http://localhost:8000/api/contacts/ \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Ada",
    "last_name": "Lovelace",
    "phone_number": "+2348012345678",
    "street": "12 Marina Road"
  }'
```

```json
{
  "status": "successfully created contact",
  "contact": {
    "contact_id": "3f1c2a0e-6c7b-4a51-9d0e-2b8f4f1c9a77",
    "first_name": "Ada",
    "last_name": "Lovelace",
    "phone_number": "+2348012345678",
    "street": "12 Marina Road",
    "created_at": "2026-10-02T14:09:00Z",
    "updated_at": "2026-10-02T14:09:00Z"
  }
}
```

List contacts (page 1, 10 per page by default):

```bash
curl "http://localhost:8000/api/contacts/?page=1&limit=10"
```

Get a contact:

```bash
curl http://localhost:8000/api/contacts/<contactId>
```

Update a contact (send only the fields you want to change):

```bash
curl -X PATCH http://localhost:8000/api/contacts/<contactId> \
  -H "Content-Type: application/json" \
  -d '{"first_name": "Augusta"}'
```

Delete a contact (returns `204 No Content`):

```bash
curl -X DELETE http://localhost:8000/api/contacts/<contactId>
```

## Development

### Changing the database schema

Create a new migration, then write the `up` and `down` SQL:

```bash
migrate create -ext sql -dir db/migration -seq <migration_name>
```

### Changing queries

Edit the SQL in `db/query/`, then regenerate the Go code in `db/sqlc/`:

```bash
sqlc generate
```

### Updating the Swagger docs

After changing the handler annotations, regenerate `docs/`:

```bash
swag init
```
